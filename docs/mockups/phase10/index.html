01 / lifecycle

Six phases. A path that draws itself.

TL;DR: every task runs DEFINE, PLAN, BUILD, VERIFY, REVIEW, SHIP. No phase is optional and each one has an exit criterion.

  1. DEFINE /spec Spec approved, scope locked
  3. PLAN /plan Tasks small, dependencies mapped
  5. BUILD /build One slice, tests written first
  7. VERIFY /verify Tests pass, behavior matches spec
  9. REVIEW /review No P0 issues, security checked
  11. SHIP /ship Clean commit, gates green

No phase is optional. Every step has a skill. Every skill has a gate.

03 / the loop

The agent that audits itself.

TL;DR: every session can audit, diagnose, fix, and record an ADR. Findings become fixes, and fixes become decisions on record.

  • 01Audit: scan core files for drift
  • 02Diagnose: classify the root cause
  • 03Fix: propose and apply with approval
  • 04ADR: record the decision
  • 05Repeat: each run raises the floor

04 / enforcement

Show the block. Do not promise it.

TL;DR: a code change with no matching test is blocked locally by L1 and cannot be merged without the remote gates check at L2.

L1

Local hooks

Fast, advisory feedback before a commit leaves your machine.

L2

Remote gates check

A required status check. The committer cannot skip it. GitHub only.

L3

CODEOWNERS review

A human owns the sensitive paths. Review is required. GitHub only.

Enforcement that adapts to your project.

TL;DR: with no git you get rules only. Add git for L1 hooks. Add GitHub for L2 and L3. Re-run init-agents after each change.

No git

L1L2L3

Independent or private, no VCS. Rules and AGENTS.md install, but there are no hooks and no remote gate. Enforcement is convention only.

Upgrade: git init then re-run init-agents

Local git

L1L2L3

A private repo or a non-GitHub forge. L1 hooks are active. There is no L2 or L3, so the remote authority is missing.

Upgrade: git remote add origin <url> then re-run init-agents

Git + GitHub

L1L2L3

Full L1 + L2 + L3. The remote gates check is required, CODEOWNERS owns sensitive paths, and the committer cannot skip either.

Apply: setup-branch-protection.sh --dry-run

Git later

L1L2L3

No git now, git and GitHub later. The key rule: re-run init-agents after git init and after adding the remote. It detects what is now available and installs the missing layers.

Rule: init-agents after each change

06 / faq

Questions, answered plainly.

What is Another Agent Skills?

A framework of 57 composable skills that turn AI coding agents into disciplined senior engineers. It adds mechanical enforcement, not just prompts. Skills follow a six-phase lifecycle: Define, Plan, Build, Verify, Review, Ship.

How does mechanical enforcement work?

Three layers. L1 is local git hooks for fast, advisory feedback. L2 is a required remote gates check that the committer cannot skip. L3 is CODEOWNERS review for sensitive paths. A code change with no matching test is blocked, locally and remotely.

Which agents does it support?

Designed for OpenCode. Portable to Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot, Windsurf, Aider, and any agent that reads AGENTS.md. The installer detects the agent and wires the matching skills and hooks.

Is it free?

Yes. MIT License. Open source. No subscriptions and no paid tiers. The installer, the skills, and the enforcement are all free.

Can an agent still break the rules?

Yes. The hooks make it harder, not impossible. An agent could misread an ambiguous approval or act outside protocol. These gates create friction, not guarantees. The human stays in the loop, and the human stays alert.

What is the Harness?

The Harness is everything around the model that turns raw intelligence into reliable output: instructions, tools, sandboxes, orchestration, guardrails, and observability. Agent equals Model plus Harness. Most agent failures are configuration failures.

How do I install it?

Three channels. Clone and run install.sh, or use the pinned curl bootstrap from the latest release, or install through npm. Then run init-agents in any project. Git and curl are live today. npm and Homebrew are coming soon.
